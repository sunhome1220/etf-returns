# 加入標的到預設清單

## 1. 確認需求

- 每檔需要：**代碼、區域、類別**。區域現有：台灣、美國、陸港、日本、印度、全球。
- **類別可以有 1～3 個**，以「、」分隔，第一個是主要類別（顏色、排序依它），例：`主動、高息`、`槓桿、市值`、`主動、金融、高息`。現有類別：主動、市值、高息、主題、槓桿、反一、金融、動能、中小、個股-科、個股-穩、報酬指數、加權指數。
- 使用者沒說區域或類別時，**先依下表從正式名稱判斷**，判斷得出來就直接用（回報時註明是依名稱判斷）；判斷不出來時才問使用者。
- 一批名單（如「其他主動式 ETF」）時，**先列出候選與分類問使用者確認**再加。名單來自網路時要註明來源，並說明會以證交所資料核對。

### 依名稱判斷類別

**主要類別**（由上往下，先符合者優先）：

| 名稱含／條件 | 主要類別 |
|---|---|
| 「主動」或代碼以 A 結尾（台股主動式 ETF） | 主動 |
| 「正2」「正二」「2X」「Ultra」「槓桿」 | 槓桿 |
| 「反1」「反向」 | 反一 |
| 「高息」「高股息」「優息」「填息」「股利」 | 高息 |
| 「金融」 | 金融 |
| 「動能」 | 動能 |
| 追蹤一個國家／地區／全球的大盤或市值前 N 大指數（台灣50、S&P 500、NASDAQ-100／QQQ、日本、印度、世界股票、VWRA…，不論台股或海外掛牌） | 市值 |
| 個股（4 碼台股代碼、非 ETF） | 個股-科（科技業）／個股-穩（電信、公用事業等）——不確定時問 |
| 產業或主題型 ETF（科技、電子、半導體、AI、電動車、5G、太空…） | 主題 |
| 證交所指數（報酬指數、加權指數） | 報酬指數／加權指數 |

**追加類別**（名稱同時符合其他條件時加上，最多共 3 個）：

| 條件 | 追加 |
|---|---|
| 「高息」「股息」「優息」「收益」（月配、季配收益型；主要類別不是高息時） | 高息 |
| 「動能」（主要類別不是動能時） | 動能 |
| 「中小」 | 中小 |
| 「金融」（主要類別不是金融時） | 金融 |
| 「科技」「創新」「AI」「成長」等主題字樣，且主要類別是主動或高息 | 主題 |
| 槓桿、反一：標的是大盤或市值型指數（台灣50、加權、S&P 500、NASDAQ-100、日本…） | 市值 |
| 「成長」「價值」等風格型的市值指數（如 00924 S&P500成長） | 主題 |

不確定時參考 `stocks.csv` 裡名稱相近的標的用哪個類別。

### 依市場與名稱判斷區域

- 投資標的在台灣（台股 ETF、台股個股）→ 台灣；名稱有「美國」「S&P」「NASDAQ」「費城」或美股代碼 → 美國；「中國」「滬深」「香港」→ 陸港；「日本」→ 日本；「印度」→ 印度；「全球」「世界」→ 全球。
- 注意「投資哪裡」而非「在哪裡掛牌」：台股掛牌的 00646 元大S&P 500 屬美國。

### 其他

- 已在清單的代碼不要重複加（若使用者要改類別，就改既有那一列）。

## 2. 改 `stocks.csv`

用 Python `csv` 模組讀寫（保留 BOM `utf-8-sig`、欄位順序 區,類,代碼,名稱,除息,Yahoo代號,成立；`lineterminator="\n"`）：

- **名稱先留空**：排程會自動補上——台股用證交所中文簡稱，其他用 Yahoo 名稱。
- 除息、Yahoo代號、成立先留空（自動判斷）；使用者有提供除息月份才填（如 `"3,6,9,12"` 或 `每月`）。
- 放在同類別或相近的位置；台股代碼不用加 `.TW`。
- 新區域（如「日本」）要同時加到「我的追蹤清單」新增代碼的區域選項：`watchlist.html` 的 `REGIONS`。

在 `app.js` 的 `CHANGELOG` 最前面加一筆（`id` 遞增）。commit、push 到工作分支。

## 3. 在分支上用真實資料核對

1. 對工作分支觸發 GitHub Actions「更新報酬率」（`update.yml`，ref＝分支）。
2. 完成後 `git pull`，從 `returns.html` 的 `const DATA = {...};` 檢查每檔：
   - `error` 沒有「查無資料」；`名稱` 正確（證交所／Yahoo 名稱）。
   - `since`（成立日）合理。Yahoo 台股歷史最早只到 2000／2008 年，較舊的標的要在「成立」欄手動填上市年。
   - `src == "twse"` 代表 Yahoo 缺歷史、已改用證交所資料（正常）。
   - 今年報酬率（`returns[今年].s`）不是 0、近期（`recent`）不是全部「上市未滿」——若是，通常是 Yahoo 只有一兩天資料，檢查證交所備援有沒有觸發。
   - `除息`：只配過一次的新標的無法推算，回報給使用者並請他提供月份。
3. 把確認後的名稱寫回 `stocks.csv`（「我的追蹤清單」頁直接讀 CSV，名稱不能空）。查無資料、或不在使用者範圍內的代碼移除，並在回覆說明原因。

## 4. 開 PR 並回報

- PR 說明：加入哪些（代碼、名稱、區域、類別）、未加入哪些及原因、核對方式與結果。
- **核對沒問題就直接合併**；有問題（查無資料、分類不確定、除息無法判斷）先回報問使用者。合併若和 main 的排程資料衝突：`returns.html` 保留分支版本，合併後對 main 再觸發一次「更新報酬率」。
- 回覆使用者：用表格列出每檔的名稱、區域、類別（註明是否依名稱判斷）、除息、今年報酬率，並說明已合併。
