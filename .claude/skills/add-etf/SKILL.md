# 加入標的到預設清單

## 1. 確認需求

- 每檔需要：**代碼、區域、類別**。區域現有：台灣、美國、陸港、日本、全球；類別沿用 `stocks.csv` 既有的（主動、市值、高息、槓桿、個股-科、個股-穩、金融、指數…）。
- 使用者沒說區域或類別時，**先依下表從正式名稱判斷**，判斷得出來就直接用（回報時註明是依名稱判斷）；判斷不出來、或同時符合多條時才問使用者。
- 一批名單（如「其他主動式 ETF」）時，**先列出候選與分類問使用者確認**再加。名單來自網路時要註明來源，並說明會以證交所資料核對。

### 依名稱判斷類別（由上往下，先符合者優先）

| 名稱含／條件 | 類別 |
|---|---|
| 「主動」或代碼以 A 結尾（台股主動式 ETF） | 主動 |
| 「正2」「正二」「2X」「Ultra」「槓桿」 | 槓桿 |
| 「高息」「高股息」「優息」「收益」「股利」 | 高息 |
| 「金融」 | 金融 |
| 指數（如報酬指數、加權指數） | 報酬指數／加權指數 |
| 追蹤大盤或市值前 N 大（台灣50、S&P 500、NASDAQ-100、全世界…） | 市值 |
| 個股（4 碼台股代碼、非 ETF） | 個股-科（科技業）／個股-穩（電信、公用事業等）——不確定時問 |
| 其他主題型 ETF（半導體、AI、電動車…） | 主題 |

### 依市場與名稱判斷區域

- 投資標的在台灣（台股 ETF、台股個股）→ 台灣；名稱有「美國」「S&P」「NASDAQ」「費城」或美股代碼 → 美國；「中國」「滬深」「香港」→ 陸港；「日本」→ 日本；「全球」「世界」→ 全球。
- 注意「投資哪裡」而非「在哪裡掛牌」：台股掛牌的 00646 元大S&P 500 屬美國。
- 已在清單的代碼不要重複加（若使用者要改類別，就改既有那一列）。

## 2. 改 `stocks.csv`

用 Python `csv` 模組讀寫（保留 BOM `utf-8-sig`、欄位順序 區,類,代碼,名稱,除息,Yahoo代號,成立；`lineterminator="\n"`）：

- **名稱先留空**：排程會自動補上——台股用證交所中文簡稱，其他用 Yahoo 名稱。
- 除息、Yahoo代號、成立先留空（自動判斷）；使用者有提供除息月份才填（如 `"3,6,9,12"` 或 `每月`）。
- 放在同類別或相近的位置；台股代碼不用加 `.TW`。
- 新區域（如「日本」）要同時加到新增代碼的區域選項：`template.html`／`returns.html` 的 `<select id="ar">` 與 `watchlist.html` 的 `REGIONS`。

在 `app.js` 的 `CHANGELOG` 最前面加一筆（`id` 遞增）。commit、push 到工作分支。

## 3. 在分支上用真實資料核對

1. 對工作分支觸發 GitHub Actions「更新報酬率」（`update.yml`，ref＝分支）。
2. 完成後 `git pull`，從 `returns.html` 的 `const DATA = {...};` 檢查每檔：
   - `error` 沒有「查無資料」；`名稱` 正確（證交所／Yahoo 名稱）。
   - `since`（成立日）合理。Yahoo 台股歷史最早只到 2000／2008 年，較舊的標的要在「成立」欄手動填上市年。
   - `src == "twse"` 代表 Yahoo 缺歷史、已改用證交所資料（正常）。
   - 今年報酬率（`returns[今年].s`）不是 0、近期（`recent`）不是全部「上市未滿」——若是，通常是 Yahoo 只有一兩天資料，檢查證交所備援有沒有觸發。
   - `除息`：只配過一次的新標的無法推算，回報給使用者並請他提供月份。
3. 把確認後的名稱寫回 `stocks.csv`（「我的追蹤清單」頁直接讀 CSV，名稱不能空）。查無資料、或不在使用者範圍內的代碼移除，並在回覆說明原因。

## 4. 開 PR 並回報

- PR 說明：加入哪些（代碼、名稱、區域、類別）、未加入哪些及原因、核對方式與結果。
- 回覆使用者：用表格列出每檔的名稱、除息、今年報酬率；提醒分支上已含最新資料，合併即生效。
- **使用者說「合併」才合併**。合併若和 main 的排程資料衝突：`returns.html` 保留分支版本，合併後對 main 再觸發一次「更新報酬率」並回報。
